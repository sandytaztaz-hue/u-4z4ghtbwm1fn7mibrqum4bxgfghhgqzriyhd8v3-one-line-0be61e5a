Entry for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun.

The program writes one funny line of text to `/output/entry.txt` — a single
self-contained joke, short enough to read in a breath. The turn lands in the
last clause: silencing the noise does not silence the problems, it only
changes how they reach you.

> I bought noise-cancelling headphones to silence my problems — now they just text me instead.

Run it with Node 22 or later:

```sh
node main.ts
```
